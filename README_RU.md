# XYESOS AI — исходный проект

Стартовый Android-проект с тёмным чёрно-фиолетовым интерфейсом и чатом через API в формате OpenAI Chat Completions.

## Что уже есть
- Android-приложение на Kotlin + Jetpack Compose.
- Поля API endpoint, модели и API-ключа.
- Настраиваемая системная инструкция.
- Отправка истории диалога и отображение ответа.
- API-ключ не записывается на диск; он остаётся в памяти экрана до закрытия процесса.

## Что потребуется
1. Android Studio на компьютере.
2. Android SDK Platform 35.
3. JDK 17.
4. API endpoint, название модели и API-ключ выбранного провайдера.

## Как собрать APK
1. Распакуй архив.
2. Открой папку `XYESOS_AI` в Android Studio.
3. Дождись Gradle Sync и установки необходимых компонентов.
4. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Важно
- Это исходный стартовый проект, а не уже собранный APK.
- Само приложение не содержит встроенную ИИ-модель и не предоставляет бесплатный API-доступ.
- Поддержка конкретного провайдера зависит от совместимости его API с форматом Chat Completions.
- Не вставляй API-ключи в публичные чаты, скриншоты или исходный код. Для опубликованного приложения безопаснее использовать собственный сервер-посредник.
- Модель и провайдер сохраняют собственные правила и ограничения. Настройки приложения не снимают их.
